- `habit_analytics.png` — Habit consistency analytics and weekly breakdown.
- `expense_tracker.png` — Yearly spending overview with Food and Extra expenses.
- `expense_analytics.png` — Spending trend chart comparing Food vs Extra spending.
- `digital_notes.png` — Notes screen showing categorized personal notes.
- `secret_vault.png` — PIN security lock screen protecting the vault.
- `password_manager.png` — Password vault showing saved credentials.
- `date_tracker.png` — Date Tracker list with Today and Tomorrow celebratory badges.

The main `README.md` is structured to automatically showcase these screenshots side by side once uploaded to your GitHub repository!
